## 使用方式

在 MATLAB（或 GNU Octave）中切換到此資料夾，執行例如：

```matlab
ex_5_2_1
```

所有檔案都在 Octave 11.3 上測試過可以執行。

## 實作摘要

- **Algorithm 2**：φᵏ = G_τ ∗ (|d|^{p/2}(1 − 2uᵏ))；φᵏ ≤ 0 處設 uᵏ⁺¹ = 1，否則為 0。當所有網格點上的 u 都不再改變時停止（Remark 1）。
- **Algorithm 3_2**：τ 依序取 0.02, 0.01, 0.005, 0.0025, 0.00125，前一個 τ 的穩態解作為下一個 τ 的初始猜測；相鄰兩個 τ 得到完全相同的解時停止。
- **卷積**：在週期計算域 [−π, π]ⁿ 上以 FFT 計算，G_τ 的 Fourier 乘子為 exp(−τ|k|²)。
- **能量**：使用 (6) 式 E^τ(u) = √(π/τ) ∫ |d|^{p/2} u G_τ ∗ (|d|^{p/2}(1 − u)) dx。
- **顯示**：重建結果畫的是 Step 1 中 φ 的零等值線（3D 為零等值面）。
- **CPU 時間**：與論文相同，不含計算 d(x) 的時間。

## 與論文不同之處

1. **距離函數 d(x) 的計算方法**
   論文以一階 Lax–Friedrichs 格式搭配 fast sweeping 解 eikonal 方程 (20)。本實作直接計算網格點到點雲的精確歐氏距離（即 (20) 要逼近的解）：
   - 有 Statistics Toolbox 時用 `knnsearch`（KD-tree）；
   - 2D 否則用分塊暴力法；
   - 3D 否則只在點雲附近一個窄帶內精確計算，窄帶外截斷為窄帶寬度。這只影響離點雲很遠、演算法用不到的區域。

2. **論文未給、由本實作自行設定的參數**
   - 2D 初始猜測圓的半徑：五瓣曲線 1.8、三瓣曲線 1.7、兩個圓 2.4、5.2.5 為 1.8、5.2.6 為 2。
   - 5.2.2 的 Algorithm 3_2 的 τ 序列：沿用 5.2.1 的 0.02, 0.01, 0.005, 0.0025, 0.00125。
   - 5.2.4 的兩個圓：圓心 (±1.2, 0)，半徑 0.7，各 100 點；雜訊 ν 為標準常態分布。
   - 5.2.5 的曲線：論文只有圖（八瓣曲線），本實作假設 r = 1 + 0.2 sin(8θ)。
   - 5.2.7 的前三個 3D 點雲依 Fig. 15 的外觀自訂：
     - 雜訊 torus：主半徑 1.2、管半徑 0.5、6000 點、雜訊 μ = 0.02；
     - 兩個互扣 torus：主半徑 1.2、管半徑 0.3，分別位於 xy 平面（圓心 (−0.6, 0, 0)）與 xz 平面（圓心 (0.6, 0, 0)），各 5000 點；
     - 凹凸 torus：主半徑 1.6，管半徑 ρ = 0.5 + 0.15 cos(12v)(0.6 + 0.4 cos(4u))，15000 點。
   - 5.2.7 初始猜測的 σ：0.3、0.2、0.25（bunny / pig 為 0.15）。σ-等值面內部以 `imfill`（或自寫的 flood fill）填滿。
   - 亂數種子固定為 `rng(1)`，點雲的隨機取樣與論文不會完全相同。

3. **5.2.6 沒有實作 SIM**
   論文拿來比較的 SIM 是另一篇論文 [10] 的方法，本實作只輸出 Algorithm 3_2 的結果與 CPU 時間。

4. **5.2.7 的 bunny 與 pig 需自備資料**
   論文未提供資料檔。把 `bunny.xyz` / `bunny.txt` / `bunny.ply`（或 `pig.*`）放在同一資料夾、每列為 x y z，程式就會讀入，並置中、縮放到最大邊長 3.6；找不到檔案會略過。

5. **5.2.7 的起始 τ 依例子調整**
   兩個互扣 torus 的管子較細，從 τ = 0.02 開始會讓整個曲面消失（即論文 Remark 3 所說 τ 不能太大）。因此起始 τ 依例子不同：雜訊 torus 0.02、凹凸 torus 0.01、兩個互扣 torus 與 bunny / pig 0.005。

6. **只用 Algorithm 2**
   依需求只重現 Algorithm 2 與 Algorithm 3_2，沒有 Algorithm 1 與 Algorithm 3_1 的結果（Fig. 5–10 中對應的那一列）。

7. **CPU 時間**
   時間取決於硬體與 MATLAB / Octave 版本，不會與論文的數字相同，只能比較趨勢。
